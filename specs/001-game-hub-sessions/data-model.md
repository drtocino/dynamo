# Data Model: Game Hub & Session Foundation

## Enums

```typescript
enum MultiplayerMode {
  RoomBased = 'RoomBased',
  SharedScreen = 'SharedScreen'
}

enum SessionState {
  Configuring = 'Configuring',
  Lobby = 'Lobby',
  Active = 'Active',
  Ended = 'Ended'
}
```

## Entities

### Game Metadata (Mocked)
Represents a game registered in the hub.
```typescript
interface Game {
  id: string; // e.g., 'trivia-pro'
  name: string;
  description: string;
  thumbnailUrl: string;
  supportedModes: MultiplayerMode[];
  settingsSchema: any; // JSON schema describing game-specific settings
}
```

### Session
The core entity managing a multiplayer match.
```typescript
interface Session {
  id: string; // UUID
  roomCode: string; // 4-6 character alphanumeric code
  gameId: string;
  hostClientId: string; // References Client.id of the creator
  mode: MultiplayerMode;
  state: SessionState;
  
  // Settings
  maxPlayers: number;
  rounds: number;
  timeLimitSeconds: number;
  gameSettings: any; // JSON object conforming to game.settingsSchema
  
  // Timestamps
  createdAt: string; // ISO 8601
  expiresAt: string; // ISO 8601 (for idle timeout, default +15m)
  
  // Navigation
  clients: Client[];
  players: Player[];
  
  // Turn Management (Shared Screen)
  activePlayerId?: string; // References Player.id
}
```

### Client
A device/browser connected to the session.
```typescript
interface Client {
  id: string; // UUID (generated by backend or frontend)
  sessionId: string;
  connectedAt: string;
}
```

### Player
An individual participant.
```typescript
interface Player {
  id: string; // UUID
  sessionId: string;
  clientId: string; // The client this player is using
  name: string; // Display name
  orderIndex: number; // 0-based index for turn order
}
```

## State Transitions (Session)
- `Configuring` -> `Lobby`: When the creator finishes settings and enters the lobby.
- `Lobby` -> `Active`: When the host clicks "Start Match".
- `Active` -> `Lobby`: When the match concludes, returning for a rematch.
- `Active` -> `Ended`: If the match is explicitly closed.
